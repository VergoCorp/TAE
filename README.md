# Thermoacoustic Engine Research Software

This is a modular, scientific desktop application for configuring, visualizing, and analyzing thermoacoustic engine designs.

## Features
- Left panel: Input parameters (engine geometry, operating conditions)
- Center panel: 3D visualization (PyVista, placeholder)
- Right panel: Tabs for results, graphs, and future AI/assistant

## Getting Started
1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Run the application:
   ```
   python main.py
   ```
